# SEO Report Generator

Two modes depending on the `output` parameter or user request:
- **Markdown** (default) — deliverable `.md` file with score gauges, color-coded tables, executive summary
- **PDF** — delegates to the Cowork `pdf` skill after generating the markdown

## When to use

Run `/seo report` as a final step after any audit command to:
- Produce a client-ready deliverable
- Format raw analysis output into a structured document
- Export to PDF for presentations or stakeholder review

## Inputs

| Source | How to handle |
|--------|---------------|
| `[url]` | Run a full audit first, then generate report from output |
| `[file]` — e.g. `ACTION-PLAN.md` | Read the file, structure into report format |
| `generate` | Build report from the current conversation analysis |

## Score gauges

Render scores as ASCII progress bars in Markdown mode:

| Score | Gauge |
|-------|-------|
| 0-19 | `[..........] XX/100` |
| 20-39 | `[##........] XX/100` |
| 40-59 | `[####......] XX/100` |
| 60-79 | `[######....] XX/100` |
| 80-89 | `[########..] XX/100` |
| 90-100 | `[##########] XX/100` |

Use `#` characters to fill proportionally: score/10 rounded = number of `#` blocks.

Example for 73/100: `[#######...] 73/100`

## Color coding

In Markdown tables, prefix status values with:
- Critical / fail: `CRIT` or emoji flag — put in "Critical Issues" table
- Warning: `WARN`
- Pass: `PASS`

Do not use HTML color spans in Markdown mode — they break in most markdown renderers.

## PDF mode

When the user requests PDF output (e.g. "export as PDF", "make a PDF", "save as PDF"):

1. Generate the full Markdown report first (save as `SEO-REPORT-[domain]-[date].md`)
2. Inform the user: "Your Markdown report is ready. To convert to PDF, I'll use the Cowork PDF skill."
3. Invoke the `pdf` skill with the generated markdown file as input
4. The PDF skill will render it with proper formatting

If the `pdf` skill is not available, deliver the Markdown report and note: "PDF export requires the Cowork PDF skill. Your report is available as Markdown."
