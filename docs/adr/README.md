# Architecture Decision Records

Short, durable notes recording a decision that is hard to reverse, surprising without context, or the result of a real trade-off. If a decision is none of those three, it does not need an ADR.

Format: one file per decision, `NNNN-slug.md`, a title and one to three sentences. Add Status, Options or Consequences only when they earn their place. The value is recording that a decision was made and why, so the next contributor does not undo it by accident.

See `../OUT-OF-SCOPE.md` for features deliberately not built, with the reason.
